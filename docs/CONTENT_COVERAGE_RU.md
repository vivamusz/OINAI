## Состав крупных сценариев
Академия юных спасателей: Безопасный дом, Светофория, Лесная тропинка, Служба 112, Помоги другу.
Адал азамат: честность, светофор, справедливый выбор, службы помощи, продолжи правило.
Миссия выполнима: найди опасность, вызови помощь (учебно, без звонка), безопасный набор, дорожные знаки.
Безопасный мир: текущий короткий маршрут повторяет существующие вопросы ЧС; полный набор ситуаций из раздела 7 ещё предстоит.
Механики M01–M15 — отдельная цель, существование игры не доказывает готовность универсального движка.
