# OINAI

Образовательные игры для детей 3–6 лет: казахский язык по умолчанию, переключение всего интерфейса на русский кнопкой RU/KZ. Занятия рассчитаны на сопровождение взрослого.

Доступны три игры:
- **ТЖ / ЧС** — 18 заданий в пяти этапах и итоговая памятка.
- **Мамандықтар / Профессии** — семь профессий, 35 вопросов, карта и пазлы.

На главном экране 13 карточек; ещё 10 игр пока показывают «Скоро».

- **Киіз үйдің құрылысы / Устройство юрты** — 3, 5 или 7 заданий: выбор детали, показ её места и итоговая памятка.

## Запуск

Нужны Node.js 24 и npm. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Для проверки и просмотра production-сборки:

```sh
npm test
npm run build
npm run preview
```

Открывать `dist/index.html` двойным щелчком не нужно: приложение запускается через HTTP-сервер.

## Устройство

React / Vite / JavaScript. `src/main.jsx` содержит оболочку и hash-маршруты, `src/content.js` — реестр карточек, `src/games/safety` и `src/games/professions` и `src/games/yurt` — независимые игровые модули. Иллюстрации находятся в `public/assets`, тесты — в `tests`.

Сайт статический: без регистрации, сервера API, рекламы и аналитики. Язык и завершённые профессии сохраняются в localStorage браузера. Незавершённый урок ТЖ при перезагрузке начинается заново. Звук необязателен.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` проверяет тесты, собирает `dist` и публикует его при обновлении `main`. В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**. Относительные пути ресурсов и hash-маршрутизация поддерживают размещение в подпапке репозитория.

## Материалы

Концепт, исходные изображения профессий и учебные материалы предоставлены владельцем проекта. Дополнительные растровые иллюстрации созданы для OINAI с помощью генерации изображений. Публичный доступ к репозиторию сам по себе не предоставляет лицензию на повторное использование материалов.

Казахские формулировки и педагогические сценарии требуют приёмки воспитателем. В ограниченной среде Codex dev-сервер ранее сталкивался с отказом доступа esbuild; production-сборка и её просмотр проверены отдельно.
